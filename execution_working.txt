NOVA AI — COMMANDS + HOW TO USE 😈⚡

==================================================
HOW TO START THE PROJECT
==================================================

STEP 1 — Open the Project

Open the NOVA-AI folder in:
- Visual Studio Code
- WebStorm

--------------------------------------------------

STEP 2 — RUN THE WEBSITE

OPTION 1 (BEST)

Install:
Live Server Extension

Then:
Right Click index.html
→ Open with Live Server

--------------------------------------------------

OPTION 2

Using Python:

python -m http.server

Then open:
http://localhost:8000

--------------------------------------------------

STEP 3 — ALLOW PERMISSIONS

Browser will ask for:
- Microphone
- Location
- Audio

ALLOW ALL.

Otherwise:
- voice assistant won’t work
- weather/location won’t work
