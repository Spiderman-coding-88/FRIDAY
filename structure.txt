NOVA AI 🤖⚡

A futuristic AI assistant inspired by Marvel's F.R.I.D.A.Y. and J.A.R.V.I.S.

NOVA AI is a cinematic web-based artificial intelligence dashboard built using:

- HTML5
- CSS3
- JavaScript
- Web Speech API
- Particle.js
- Three.js

This project combines:
- voice interaction
- holographic UI
- futuristic animations
- intelligent command handling
- cinematic sci-fi design

into a single immersive AI experience.

==================================================
HOW TO RUN
==================================================

1. Clone or Download

git clone https://github.com/yourusername/NOVA-AI.git

OR

Download ZIP manually.

--------------------------------------------------

2. Open Project

Open the folder using:
- VS Code
- WebStorm
- Sublime Text

--------------------------------------------------

3. Run Local Server

VS Code Live Server:
- Install Live Server extension
- Right click index.html
- Open with Live Server

OR

Python server:

python -m http.server

--------------------------------------------------

4. Allow Permissions

Browser permissions required:
- microphone access
- geolocation access
- audio autoplay
